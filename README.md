# Ocasio Comment Link Remover

> Lightweight WordPress plugin to strip author website links and URLs from comments to eliminate backlink spam.

## Overview

Spammers target WordPress comments to drop useless links. **Ocasio Comment Link Remover** removes the website URL input field from comment forms and unlinks author names so spam bots get zero backlinks.

## Features

* **Remove Website URL Field:** Hides the website input box from the WordPress comment form.
* **Unlink Comment Author Names:** Converts hyperlinked author names to plain text.
* **Cookie Consent Cleanup:** Keeps cookie labels clean and concise.
* **Zero Front-End Assets:** Pure PHP execution with 0 bytes of extra CSS or JS loaded on public pages.
* **Instant Dashboard Toggle:** Manage and toggle the switch directly from the **Ocasio Plugins** dashboard.

## Installation

1. Click the green **`< > Code`** button at the top of this repository and select **Download ZIP** (or download from [Releases](../../releases)).
2. In your WordPress admin dashboard, navigate to **Plugins -> Add New Plugin -> Upload Plugin**.
3. Choose the downloaded `ocasio-comment-link-remover.zip` file and click **Install Now**.
4. Click **Activate Plugin**.
5. Manage settings directly under the **Ocasio Plugins -> Dashboard** menu.
